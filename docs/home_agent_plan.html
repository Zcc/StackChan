StackChan HomeAgent 实施计划

目标是在不破坏小智平台能力的前提下，为 StackChan 新增一条可外出使用的 HomeAgent 通道，让它通过手机热点或任意 Wi-Fi 连接到公网 WSS relay，再由家里电脑上的 agent bridge 接入 Codex、OpenClaw、Hermes 等 agent。

固件新增 HomeAgent 模式 保留 AI.AGENT / 小智链路 WSS relay 穿透 MCP / HTTP / WebSocket bridge 320 x 240 屏幕设计

目标架构

StackChan 和家里电脑都主动连公网 relay，因此不需要给家里电脑开公网端口，也不要求 StackChan 支持 Tailscale。

StackChanHomeAgent 固件模式，主动连 WSS，收控制包，发 JPEG/状态。
→
VPS / Cloudflare Relay按 deviceId 配对 device 与 agent，只做转发和鉴权。
→
Home Agent Bridge运行在家里电脑，暴露 MCP、HTTP、本地 WebSocket。
Codex / OpenClaw / Hermes
  -> stackchan-agent-bridge
  -> wss://relay.example.com/ws?role=agent&deviceId=<id>
  -> StackChan HomeAgent firmware

实施路线图

Phase 1
MVP 闭环

让 StackChan 能被家里电脑控制

  • 固件新增或复用 HomeAgent/AVATAR WebSocket client。
  • Relay 支持 role=device 和 role=agent 两类连接。
  • Bridge 支持 /say、/move、/avatar、/status。
  • 验收：StackChan 通过手机热点连 relay，电脑端 curl 一次能说话和转头。
Phase 2
图像能力

接入视频流和单次抓拍

  • 复用现有 0x05 StartCameraStream、0x06 StopCameraStream、0x02 Jpeg。
  • 补齐固件侧 0x1A AimedTakePhoto，用于单次抓拍。
  • Bridge 保存 latest.jpg 和 latest_photo.jpg。
  • 验收：agent 能调用抓拍，并拿到 JPEG。
Phase 3
Agent 工具化

让不同 agent 使用统一工具

  • Codex 优先走 MCP tools。
  • OpenClaw/Hermes 可走 HTTP 或本地 WebSocket。
  • 工具包括 stackchan_say、stackchan_move、stackchan_take_photo 等。
Phase 4
配置安全

去掉硬编码，加入认证和状态

  • Relay URL、deviceId、token 存 NVS。
  • 早期用 Bearer token，正式版升级 HMAC/JWT。
  • HomeAgent 页面显示 Wi-Fi、Relay、Agent、Camera 状态。

边界原则

  • 不改 AI.AGENT 的小智启动链路。
  • 不把 HomeAgent 伪装成小智平台。
  • 优先复用现有 AVATAR WebSocket 协议。
  • StackChan 只主动出站连接，不做公网 server。
  • BLE 只用于配置或低频控制，不承载图像。
最终菜单建议：
AI.AGENT 继续连接小智；
HOME_AGENT 连接你的电脑 agent；
SETUP 管理 Wi-Fi 和 relay 配置。

协议设计

继续使用现有二进制包格式：

[type: 1 byte][length: 4 bytes big endian][payload]
类型方向用途
0x03Agent → StackChanControlAvatar，控制表情、眼睛、嘴型。
0x04Agent → StackChanControlMotion，控制 yaw/pitch 舵机。
0x07Agent → StackChanTextMessage，在头像上显示来自 agent 的文字。
0x14Agent → StackChanDanceSequence，播放动作序列。
0x05Agent → StackChan开始连续摄像头流。
0x06Agent → StackChan停止连续摄像头流。
0x02StackChan → Agent连续 JPEG 帧。
0x1A双向单次抓拍请求和 JPEG 响应。

Bridge 工具接口

家里电脑上的 bridge 把 agent 友好的工具调用翻译成 StackChan 协议包。

stackchan_say(text)
stackchan_move(yaw, pitch, speed)
stackchan_avatar(json)
stackchan_expression(emotion)
stackchan_dance(sequence)
stackchan_take_photo()
stackchan_start_camera()
stackchan_stop_camera()
stackchan_get_latest_frame()
stackchan_status()

同时建议保留本地 HTTP API，方便 OpenClaw、Hermes 或脚本接入：

POST /move
POST /camera/take-photo
POST /camera/start
POST /camera/stop
GET  /camera/latest.jpg
GET  /status

外出网络变化处理

HomeAgent 不能假设网络固定。StackChan 应该维护一个已知 Wi-Fi 列表，并提供 BLE 临时配网入口；外出时最常见的是连接手机热点。

场景处理方式屏幕提示
已保存网络可用启动后按优先级自动连接，例如家里 Wi-Fi、手机热点、常用办公 Wi-Fi。Wi-Fi connecting → Relay connecting
外出网络变了StackChan 进入 config-needed 状态，开启 BLE 配网服务；手机 App 写入新的 SSID/password。No Wi-Fi、显示 BLE config 提示。
手机热点手机先开热点，App 通过 BLE 把热点 SSID/password 写入 StackChan，StackChan 连接后再连 WSS relay。Hotspot connected、随后显示 relay 状态。
Portal 网络酒店/机场网页认证网络不建议作为主方案；优先使用手机热点或随身路由器。Wi-Fi blocked 或 Relay timeout
固件侧建议保存多个 Wi-Fi profile，并记录最后成功连接的网络。失败时不要卡死 HomeAgent 页面，应保留 BLE 配网和返回 Launcher 的入口。

VPS 与家里电脑改造

VPS 只做公网 relay；家里电脑做 agent bridge。这样安全边界清楚，agent、本地文件和模型能力都留在家里电脑上。

位置需要部署/修改职责
VPS / Cloudflare部署 stackchan-relay，监听 wss://relay.example.com/ws。接受 device/agent 两类连接，按 deviceId 配对转发。
VPS / Cloudflare配置 TLS、反向代理、鉴权 token、心跳超时和日志。保证外网可达，拒绝未授权连接，记录上下线和错误。
家里电脑部署 stackchan-agent-bridge，作为 WSS client 主动连接 relay。把 MCP/HTTP/WS 命令翻译为 StackChan 二进制协议。
家里电脑增加 MCP server、HTTP API、本地图片缓存和自动重连。给 Codex/OpenClaw/Hermes 提供统一工具接口。
家里电脑设置开机自启，例如 launchd/systemd/pm2。保证你不在家时 bridge 也在线。
 
VPS relay:
  device websocket: role=device, deviceId=stackchan-xxxx
  agent websocket:  role=agent,  deviceId=stackchan-xxxx

Home computer bridge:
  connects to relay
  exposes MCP tools to Codex
  exposes http://127.0.0.1:8787 for other agents
  stores latest camera frame locally

HomeAgent 屏幕设计

StackChan 屏幕是 320 x 240。HomeAgent 页面要一眼分辨当前不是小智模式，而是连接家里电脑 agent 的远控模式；同时不能遮挡头像表达。

主屏布局规格

  • 顶部 24px 霓虹状态栏：左侧显示 HOME_AGENT 和连接灯，右侧只放 Wi-Fi、电量等短信息。
  • 主视觉头像区：头像占据约三分之二屏幕宽度，表情成为第一视觉，状态信息退到 HUD 层。
  • 右侧 HUD 芯片：Relay、Agent、Camera 压缩成 3 个小徽标，不再占大面板空间。
  • 底部角色对白：显示最近一条 agent 消息，像 StackChan 自己在说话，而不是系统日志。
  • 赛博朋克视觉：深色底、细网格、青绿色在线光、品红高光；实现时可用 LVGL 纯色、边框和简单渐变近似。

交互规则

  • 短按右侧 HUD 芯片：切换详细信息页，显示 deviceId、relay host、IP、RSSI。
  • 长按屏幕底部：断开 HomeAgent 并回到 Launcher。
  • 收到 TextMessage：底部消息条更新，头像触发 SpeakingModifier。
  • 抓拍或视频流开启：Camera 行从 idle 变为 capture 或 streaming。

固件改造点

文件/模块改造内容备注
app_home_agent 或 app_avatar新增 HomeAgent 入口和状态页。推荐独立 app，避免混淆小智入口。
hal_ws_avatar.cpp支持 relay URL/token、0x1A 抓拍、状态回调。复用现有 WebSocket worker。
secret_logic / NVS config读取 home_agent.relay_url、device_id、auth_token。MVP 可先硬编码，正式版存 NVS。
Setup 或 BLE config配置 relay 地址、token、启用开关。可作为第四阶段完成。
小智相关路径保持不动：AI.AGENT 仍调用 GetHAL().requestXiaozhiStart()，最终进入 GetHAL().startXiaozhi()。
